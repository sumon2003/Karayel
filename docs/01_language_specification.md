# Karayel Programming Language Specification

Version: 1.0

Language Name: Karayel

File Extension: .kl

---

## 1. Introduction

Karayel is a simple, beginner-friendly programming language developed using Flex and Bison.

The language is designed to provide a clean and easy syntax while supporting the essential programming features such as variables, arithmetic operations, conditional statements, loops, input/output, and functions.

Karayel uses automatic type detection (type inference), so programmers do not need to specify variable types manually.

## 2. Design Goals

The primary goals of Karayel are:

- Simple syntax
- Easy to learn
- Easy to read
- Automatic type detection
- Beginner friendly
- Lightweight interpreter

## 3. File Extension

All Karayel source files use the following extension:

.kl

## 4. Reserved Keywords

The following words are reserved and cannot be used as variable names.

- KL
- Show
- Scan
- task
- give
- if
- else
- while
- for
- true
- false
